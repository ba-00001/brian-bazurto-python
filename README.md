here and nothing else is. Weeks 10 and 11 share **one branch and one pull
request**: Week 11 extends the Week 10 program rather than replacing it, and the

Every pull request is intentionally left **open**. The pull request *is* the
submission — merging it would close the page the reviewer is meant to read.

## Final project — Country Explorer

Assignments 10 and 11 build one program: a command-line tool over live World
Bank country data, with case-insensitive name search, region ranking by
population, two-country comparison, and a cleaned CSV export (Week 11,
**Option B — Data Cleaning & CSV Export**).

```bash
git clone https://github.com/ba-00001/python-intro-final-project.git
cd python-intro-final-project && git checkout week-10-final-project
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python main.py
```

### Why not REST Countries

The course material recommends `restcountries.com/v3.1` for Assignments 9–11.
**That API was deprecated during the course.** It now answers with HTTP `200`
and an error body rather than country data:

```json
{"success": false, "data": null,
 "errors": [{"message": "This API version has been deprecated..."}]}
```

Its v5 replacement requires an API key (`Authorization: Bearer YOUR_KEY`), so it
is no longer a keyless public API and no longer fits the assignment brief.
Assignments 9, 10 and 11 use the **World Bank Indicators API** instead — public,
keyless, no registration, and it carries every required field. Assignment 9's
warmups 1 and 2 still use Agify exactly as specified. The full rationale is in
each affected assignment README.
